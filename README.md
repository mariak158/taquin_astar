Taquin Puzzle Solver (A*)
This is a small Python project where I worked on solving the Taquin (Sliding Puzzle) using the A* search algorithm.
What I used
Python
A* Search Algorithm
Manhattan Distance
Tkinter for the GUI
About the project
The goal is to find a solution to the puzzle by moving the tiles into the correct positions.
Working on this project helped me better understand search algorithms, heuristics, and how some AI concepts work in practice.
